# UCR Pathways video assets

Vector SVG exports of the full UCR curriculum butterfly and the six individual clusters. These are the current source graphics for video production and include course identifiers.

These images are inputs to the experimental curriculum-video sub-project, whose agreed concept, storyboard, narration, source records, technical tests and continuation instructions are documented in [the pilot production brief](../../pilot/curriculum-video/README.md).

Current assets:

- `curriculum.svg` — complete butterfly
- `BEN.svg` — Business & Entrepreneurship
- `DIS.svg` — Data Science & Intelligent Systems
- `ENS.svg` — Environment & Sustainability
- `GOS.svg` — Government & Society
- `HCB.svg` — Health, Cognition & Behavior
- `MCC.svg` — Media, Culture & Communication

The SVGs are source visuals, not rendered videos. Rendered MP4s are delivered as temporary GitHub Actions artifacts, not committed here.
