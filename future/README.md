# Future ideas and implementation plans

This folder contains possible future extensions and implementation plans for UCR Pathways.

Its contents are **not** current product requirements, production instructions, or implementation commitments. They must not affect current academic production, validation, rendering, or publication unless an explicit decision is made to implement them.

Each substantive future feature should have its own file. When an idea is approved for implementation, its relevant durable decisions and operating rules should be incorporated into the appropriate authoritative documentation and implementation state. The future-plan file may then be updated, archived, or removed as appropriate.
